# MA55 板块观察 · lan.ma55 0.10.0

在 TSP v0.3.36 的「MA55 板块观察」打开 `/lan-ma55`。搜索同花顺行业或概念，确认实际板块代码，再点「保存并更新」。保存以后台回执为准。首次七个关注方向是草稿，名称相近的细分供手动确认。各板块保留完整成分，同一只股票保留全部归属。保存空股池会暂停采集，历史仍可查看。

列表默认显示所有关注股。点击股票名直接看同页 K 线，点击周期格可定位已有的结构确认。「官方详情」使用 TSP 的个股详情入口。「冻结 BUY 历史」可按原确认时刻打开存量行情。题材与行业页面的旧事件继续携带原时间、来源和事件 ID。

## 数据和观察口径

- 同花顺目录和成分使用 `THS_API_TOKEN`，也可在插件私有 `settings.json` 提供 `ths_api_key`。目录和成分分别显示源时间，成分刷新失败保留旧快照。盘前按交易日更新。 [同花顺指数接口](https://fuyao.aicubes.cn/docs/api-reference/a-share-index/)
- TickFlow 原生完成 15m 和同源原价日线共用现有 owner、请求收据、8 RPM 主池和 2 RPM 深历史池。30/60/120m 聚合完整半日内的 2/4/8 根 15m。周线使用实际最后交易日完成的日线。 [上交所 2026 年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)
- 六周期独立运行 `MA55_MULTIFRAME_R1_RESEARCH_V1`。首次满足至少 150 根连续有效柱时固定回放起点，之后只推进已完成周期或按修订重放。缺柱、历史深度、最小报价单位和因子不足按周期显示。历史补齐标为 REPLAY。
- 上方 MA55 使用同一前复权基准及最新有效完成 15m 参考价，按价格排序。可展开六个周期的距离、确认时间和反压观察，图表默认显示本周期 MA55。

## 构建和恢复

在现有 `nga` 环境中运行定向 pytest，使用 pnpm 构建页面，再运行 `build_backend.py` 生成官方扩展包。产物由「设置 → 导入与备份」预检和安装，生效需要正常重启。主题使用 `lan.theme 1.0.8`，行业页面使用 `lan.sector_focus 1.0.2` 的整合深链。

回退前用 SQLite backup API 保存当前插件库，再通过官方管理器将 `lan.ma55` 回退到 0.9.8 并启用 `lan.kline 3.3.0`。如需恢复旧链接，回退题材包并重导入备份的行业页面。现库保留新增表和事件，可供后续恢复。交付依据见 [整合验收](SECTOR_MULTIFRAME_INTEGRATION.md)。
