# MA55 板块观察 · lan.ma55 0.11.0

在 TSP v0.4.1 打开「MA55 板块观察」`/lan-ma55`。从同花顺板块库按名称、代码或别名搜索，按行业和概念筛选，可分页查看板块成分和指定股票的归属。加入板块或自定义组后，点「预览变更」查看去重后的新增、退出、保留股数，再点「保存关注」。组、别名和待加入板块随同一份草稿保存。首次关注方向提供搜索入口，已有关注照常显示。清空关注后行情采集暂停，分类库与冻结历史仍可查阅。

列表默认显示所有关注股。点击股票名直接看同页 K 线，点击周期格可定位已有的结构确认。「官方详情」使用 TSP 的个股详情入口。「冻结 BUY 历史」可按原确认时刻打开存量行情。题材与行业页面的旧事件继续携带原时间、来源和事件 ID。

## 数据和观察口径

- 同花顺目录和成分使用 `THS_API_TOKEN`，也可在插件私有 `settings.json` 提供 `ths_api_key`。工作台分别显示接口时间、核验时间和证据类型。后台在盘前查目录和已关注成分，按周核验整库，也可从页面安排更新。新代成分核实后一次切换，同一个 `state.sqlite3` 保留上一成功代，待建进度可续跑。 [同花顺指数接口](https://fuyao.aicubes.cn/docs/api-reference/a-share-index/)
- 证券全集取 TickFlow `CN_Equity_A`，由沪深北股票主数据核对代码。反查按 100 股分批，以正向名单抽样核验。发现两向差异的类别使用逐板块正查。完整库的各质量状态和已核实的行业与概念细分样例见 [本次验收](V041_TAXONOMY_HANDOFF.md)。
- TickFlow 原生完成 15m 和同源原价日线共用现有 owner、请求收据、8 RPM 主池和 2 RPM 深历史池。30/60/120m 聚合完整半日内的 2/4/8 根 15m。周线使用实际最后交易日完成的日线。 [上交所 2026 年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)
- 六周期独立运行 `MA55_MULTIFRAME_R1_RESEARCH_V1`。首次满足至少 150 根连续有效柱时固定回放起点，之后只推进已完成周期或按修订重放。缺柱、历史深度、最小报价单位和因子不足按周期显示。历史补齐标为 REPLAY。
- 上方 MA55 使用同一前复权基准及最新有效完成 15m 参考价，按价格排序。可展开六个周期的距离、确认时间和反压观察，图表默认显示本周期 MA55。

## 构建和恢复

在现有 `nga` 环境中运行定向 pytest，使用 pnpm 构建页面，再运行 `build_backend.py` 生成官方扩展包。产物由「设置 → 导入与备份」预检和安装，生效需要正常重启。新版使用宿主主题和个股详情。历史链接将路径改为 `/lan-ma55`，保留 `symbol`、`period`、`event` 和 `event_id`。旧原生 15m 候选使用 `source=native`，冻结 BUY 使用 `source=archive`。

回退使用与插件版本匹配的宿主和停机时保存的数据目录。`lan.ma55 0.9.8` 及旧页面的回退包随 v0.3.36 安装保全，SQLite 使用备份 API 保存。旧版证据见 [整合验收](SECTOR_MULTIFRAME_INTEGRATION.md)。
