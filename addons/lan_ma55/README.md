# MA55 板块观察 · lan.ma55 0.13.8

在 TSP v0.4.1 打开「MA55 板块观察」`/lan-ma55`。首屏显示运行阶段、15m 覆盖、已保存关注和六周期股票矩阵。点「关注管理」可按行业、概念、题材或我的关注组浏览东财板块库，也可按名称、代码、别名和组名搜索。行业树可展开三级，任一级都可加入关注。成分详情分页展示股票与题材入选原因，输入股票代码可查所属板块及行业路径。

「关注管理」的合计是各板块有效成分数相加，去重是按证券代码合并后的股数。添加或移除板块后，摘要会更新草稿统计。点「预览变更」核对新增、退出和保留，再点「保存关注」。后台复核保留草稿，涉及差集变化时会请你确认新范围。另一窗口保存后，重新预览会将当前草稿改动合并进最新配置。组、别名和选中板块随同一份草稿保存。旧同花顺关注的迁移仍需核对名单差集并明确确认。清空关注后暂停行情采集，分类库与冻结历史仍可查阅。

列表默认显示所有关注股。「最新激活」按周期显示完成目标、覆盖与该柱确认的股票。分钟周期切到「今日」可看核实交易日内经有效回放确认的买点，展开后可定位同一股票的较早确认。补算沿用原有事件 ID 和确认时间。点股票名看同页 K 线，点激活格或结果行定位对应周期和确认柱。「官方详情」使用 TSP 的个股详情入口。「冻结 BUY 历史」按原确认时刻打开存量行情，旧链接保留来源和事件 ID。

## 数据和观察口径

- 分类使用已配置的 Tushare 兼容 HTTPS 网关，读取环境变量 `TUSHARE_RELAY_URL` 和 `TUSHARE_RELAY_TOKEN`。行业、普通概念和日度题材分别保留东财代码。三级树标为「东财成分关系重建」`DERIVED_FROM_DC_MEMBERSHIP`，父子边由同日完整名单的唯一包含与并集闭合确定。 [东财板块目录](https://tushare.pro/document/2?doc_id=362) · [东财板块成分](https://tushare.pro/document/2?doc_id=363)
- 优先复核已关注板块。北京时间 21:00 后尝试当日数据，实际日期来自经核验的源响应。整库按周、目录变化或手动操作分批更新，默认每分钟最多 18 次分类请求，可在插件私有 `settings.json` 设置 `dc_requests_per_minute`。有有效名单的「待复核」板块仍可添加。详情显示名单日期、核验时间和复核目标。同一个 `state.sqlite3` 保留当前代、上一有效代和待建进度。
- 证券范围取 TickFlow 沪深北在市 A 股证券主数据。整库保留原始成分关系，关注池和详情采用范围内名单。完整树、各类板块成分和样本差异见 [东财验收](DC_TAXONOMY_ACCEPTANCE_20261124.md)。
- TickFlow 原生 15m、同源原价日线及复权使用一个行情 owner。新完成的 15m 目标优先，其次补当前 15m 分析所需缺口和复权，再交替处理长周期与日线任务。跨证券合并相邻缺口，每次 HTTP 按证券数和窗口大小分批。现用 8 RPM 主池和 2 RPM 深历史池，可通过 `minute_requests_per_minute` 和 `cold_requests_per_minute` 配置。30/60/120m 由 2/4/8 根对齐的 15m 聚合，周线由交易日历确认的完整周日线聚合。 [上交所 2026 年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)
- 六周期独立运行 `MA55_MULTIFRAME_R1_RESEARCH_V1`。首次满足至少 150 根连续有效柱时固定回放起点，之后只推进已完成周期或按修订重放。缺柱、历史深度、最小报价单位和因子不足按周期显示。历史补齐标为 REPLAY。
- 15m 到达与分析就绪分别按当前完成目标计数。矩阵按周期区分激活、未激活、待算与缺数据。四个分钟周期累计当日确认，日K和周K分别使用最后完成柱，激活股票按六周期有效窗口的并集去重。目标、关注修订或发布结果不匹配时，计数等待有效投影。旧结果快照可读到当次回放的最近确认，多次确认从新版成功回放开始记录。输入修订后无法复现的事件仍保留在历史证据中。
- 上方 MA55 使用同一前复权基准和最新有效完成 15m 参考价。图内按本周期完成柱计算 MA5、MA10、MA20、MA30、MA55、MA233，可分别切换显示。十字光标和默认最新读数都使用所指完成柱。图表最多显示 250 个时点，另读最多 232 根本周期前置柱。历史不够或窗口断开时均线留空。读图只查本地库存，旧归档仍支持原有 15/30/60m。
