# MA55 板块观察 · lan.ma55 0.13.2 候选版

在 TSP v0.4.1 打开「MA55 板块观察」`/lan-ma55`。首屏显示运行阶段、15m 覆盖、已保存关注和六周期股票矩阵。点「关注管理」可按行业、概念、题材或我的关注组浏览东财板块库，也可按名称、代码、别名和组名搜索。行业树可展开三级，任一级都可加入关注。成分详情分页展示股票与题材入选原因，输入股票代码可查所属板块及行业路径。

加入板块或自定义组后，点「预览变更」查看去重后的新增、退出、保留股数，再点「保存关注」。组、别名和选中板块随同一份草稿保存。旧关注归档列出同花顺板块、组和别名。已有板块的迁移需要选择对应东财板块、查看名单交集及差集，再明确确认。首次关注方向提供搜索入口。清空关注后行情采集暂停，分类库与冻结历史仍可查阅。

列表默认显示所有关注股。点击股票名直接看同页 K 线，点击周期格可定位已有的结构确认。「官方详情」使用 TSP 的个股详情入口。「冻结 BUY 历史」可按原确认时刻打开存量行情。题材与行业页面的旧事件继续携带原时间、来源和事件 ID。

## 数据和观察口径

- 分类使用已配置的 Tushare 兼容 HTTPS 网关，读取环境变量 `TUSHARE_RELAY_URL` 和 `TUSHARE_RELAY_TOKEN`。行业、普通概念和日度题材分别保留东财代码。三级树标为「东财成分关系重建」`DERIVED_FROM_DC_MEMBERSHIP`，父子边由同日完整名单的唯一包含与并集闭合确定。 [东财板块目录](https://tushare.pro/document/2?doc_id=362) · [东财板块成分](https://tushare.pro/document/2?doc_id=363)
- 盘前核对上一完整交易日的目录和当前关注成分。插件将北京时间 21:00 用作开始核对当日盘后数据的本地时间阈值，实际采用通过完整性校验的数据日期。整库按周、目录变化或手动操作分批更新，默认每分钟最多发起 18 次分类请求，可在插件私有 `settings.json` 设置 `dc_requests_per_minute`。局部已关注名单保留自己的数据日期。最后有效的整库可继续搜索和预览，同一个 `state.sqlite3` 保留当前代、上一有效代和待建进度。
- 证券范围取 TickFlow 沪深北在市 A 股证券主数据。整库保留原始成分关系，关注池和详情采用范围内名单。完整树、各类板块成分和样本差异见 [东财验收](DC_TAXONOMY_ACCEPTANCE_20261124.md)。
- TickFlow 原生完成 15m 和同源原价日线共用现有 owner、请求收据、8 RPM 主池和 2 RPM 深历史池。30/60/120m 聚合完整半日内的 2/4/8 根 15m。周线使用实际最后交易日完成的日线。 [上交所 2026 年休市安排](https://www.sse.com.cn/disclosure/announcement/general/c/c_20251222_10802507.shtml)
- 六周期独立运行 `MA55_MULTIFRAME_R1_RESEARCH_V1`。首次满足至少 150 根连续有效柱时固定回放起点，之后只推进已完成周期或按修订重放。缺柱、历史深度、最小报价单位和因子不足按周期显示。历史补齐标为 REPLAY。
- 15m 就绪与未就绪按当前完成目标及生效范围计数。结构候选在六周期按证券去重。缺少目标、关注修订或结果发布代尚未匹配时，覆盖项显示「—」。运行详情独立显示六周期覆盖、行情水位和分析水位。
- 上方 MA55 使用同一前复权基准及最新有效完成 15m 参考价，按价格排序。可展开六个周期的距离、确认时间和反压观察，图表默认显示本周期 MA55。

## 构建和恢复

2026-11-25，TSP v0.4.1 正式启用 `lan.ma55 0.12.0`，加载 2026-11-24 的东财完整分类。生产关注池为空，冻结历史可从工作台打开。`0.11.0` 可通过官方扩展管理回退。 [正式安装与清理验收](DC_PRODUCTION_INSTALL_CLEANUP_20261124.md)

`0.13.2` 用于隔离验收，正式安装单独决定。 [工作台改版验收](UI_REDESIGN_ACCEPTANCE_20261126.md)

在现有 `nga` 环境中运行定向 pytest，使用 pnpm 构建页面，再运行 `build_backend.py` 生成官方扩展包。产物由「设置 → 导入与备份」预检和安装，生效需要正常重启。新版使用宿主主题和个股详情。历史链接使用 `/lan-ma55`，保留 `symbol`、`period`、`event` 和 `event_id`。旧原生 15m 候选使用 `source=native`，冻结 BUY 使用 `source=archive`。

需要回退时，停掉宿主并保存现场，核对版本相符的旧包、安装状态、配置和 SQLite 一致性备份，再通过官方扩展管理回退并重启。需要从 ZIP 恢复时，先用官方扩展管理卸载候选并重启，再导入旧包。验证旧关注和冻结历史后再恢复日常使用。 [同花顺归档验收](V041_TAXONOMY_HANDOFF.md) · [六周期整合验收](SECTOR_MULTIFRAME_INTEGRATION.md)
