# 行业强度与 MA55 · Page Pack 1.0.0

独立页面 `/lan-industry`，清单 ID `lan.sector_focus`，安装存储 ID
`lan_sector_focus`。基于宿主 v0.3.36 / Page SDK v1，使用宿主主题变量。
只做行业排序和人工观察交集，不改变 MA55 规则、事件、采集频率或关注池。
概念和 AI 不参与评分；没有新增后台线程、定时任务、行情源或供应商 SDK。

## 分类口径

页面标题固定为“同花顺行业（扁平）”。现有 `ext_hy_ths` 没有权威层级 ID；
Fuyao fanout 把一个股票的多个目录名称用 `-` 拼成字符串。
因此含 `-` 的记录全部列入“分类待核实”，不拆成行业，也不把整个拼接字符串当新行业。
其中也可能存在名称本来带连字符的目录；缺原始目录 ID 时无法区分。

其余名称整串精确匹配。`/`、空格和大小写中的文字不会拆分、模糊合并或猜父子关系。
如果宿主 RPS 已把某名称拆开，原名称无法取得20日历史，显示缺失日期和 NA。
同一证券可以有多条已明确行业记录，成员按完整 `.SH/.SZ/.BJ` 代码去重，保留全部所属行业。
裸代码和未取得可信归属的 ETF 不推断行业。

分类版本由源表 ID、快照文件写入时间、配置更新时间和声明行数组成，不创建额外摘要体系。
文件写入时间仅表示本机观察版本；现有公开响应未提供供应商原始生效日期。
页面明确提示“以最新行业归属回看历史”，不据此声称历史当时分类或无偏回测。

## 数据流与有效条件

`src/data.mjs` 只调用 `ctx.api` 的正式同源读取：

1. `extDataList()` 读取行业配置和保存时间。
2. `extDataRows('ext_hy_ths', {limit:20000, columns:[...]})` 读取精确归属。
3. `marketSnapshot()` 读取全市场同日比较基准。
4. `rpsRotation(21, 'industry')`，不传 `level`。多取一日，丢弃北京时间15:00前
   的当日列和未来列，再取最近20个真实有数据交易日。
5. 仅读取 `lan_ma55_native15_summary_v1`、`lan_ma55_native15_day_v1`。
6. 选择行业时调用 `dimensionMembers(...)`，返回结果再次按完整快照的行业名和
   完整证券代码精确核对；接口片段匹配不会产生新归属。
7. `extPagesList()` 检查独立15m工作台，兼容正式整包的 `managed_by='lan.kline'` 元数据。

读取必须核对 `total === rows.length`。当前 SDK 的 `extDataRows` 没有 offset 参数，
不能虚构分页调用；超过单次上限时标记 `INCOMPLETE_MEMBERSHIP` 或候选投影不完整。
列表的行业分页和成分页只处理当前页面快照，不发逐股票请求。

只有行业名称在20个日期都有有限涨跌幅、快照保存日期不早于评分日、快照读取完整时才有分数。
若全市场快照或 MA55 已证明存在更晚的已完成交易日，旧矩阵标记 `STALE_RPS`。
其他异常标记 `INSUFFICIENT_HISTORY` / `STALE_MEMBERSHIP`，不补零；
可用行业 KPI 仅计有效排名。未知的供应商原始时间始终单独披露。

初次空矩阵显示无排名；刷新失败时保留上次成功快照并明确标旧。
没有自动重试、清宿主缓存或刷新生产流水线的操作。普通市场快照读取也是计算比较基准的输入，
随后读取 RPS；这并未修复宿主扩展发布清缓存与 RPS 空响应的上游问题。

## 试验评分 FLAT_INDUSTRY_RANK_V1

这是**已明确分类子集内**的描述性排序，不是全行业指数榜。
先排除分类待核实项，再把每日成员平均涨跌幅降序排列；同涨跌幅按中文名称排序。
设当日有 N 个可用行业，排名为 r，排名百分位 `p = 1 - (r-1)/(N-1)`；N=1时 p=1。

- 持续性：20日内进入 Top10 的天数除以20，同时展示 Top20 天数。
- 近5日：最近5个真实数据日的平均 p。
- 5日变化：近5日平均 p 减20日平均 p，展示为百分点。
- 强度：`100 × (0.70 × Top10天数/20 + 0.30 × 近5日平均p)`，保留一位小数。
- 最新日相对全市场：该行业同日平均日涨跌幅减全市场有效股票日涨跌幅等权平均。
  基准日期不一致或不存在时为 NA；该项不混入强度分。

分类先判断新晋和退潮，再判断持续强势：

- 新晋走强：5日变化 ≥ 20个百分点，且近5日 p ≥ 60%。
- 明显退潮：5日变化 ≤ -20个百分点，且近5日 p ≤ 40%。
- 持续强势：Top10 ≥ 10天，且近5日 p ≥ 60%。
- 其余为观察；输入不合格为数据待核实。

权重和阈值冻结在本插件，尚未做收益或样本外有效性验证。
没有把每日排名、复合收益、成交额或价量活跃写成权威行业20日收益或真实资金净流入。

## MA55 和深链

只接受 `NATIVE15_REVIEW_V1`、`TICKFLOW_NATIVE_15M` 的当日原生事件。
相同 event_id 的重复投影去重，不同 event_id 的独立事件完整保留；股票列表只出现一次。
`event_id / confirmed_at / mode / source_id / rule_version / basis_id / factor_revision /
basis_revision` 保持原值。REPLAY 不改成 LIVE。旧冻结 BUY 表完全不读取、不写入。

默认“行业榜 → 成分/候选侧栏”，可以切换全部成分，也可检查未映射候选。
候选链接进入现有 `/lan-kline`，带完整证券、15m、事件时间、事件 ID、来源和价格基准。
工作台未启用时保留官方 `ctx.ui.openStockPreview`。评分是收盘后观察，
不会回填成更早盘中确认的理由，也不自动提升底层采集优先级。

## 构建、安装、回退

在本目录运行：

```text
pnpm install --frozen-lockfile
pnpm test
pnpm build
```

产物 `dist/extension.js`，按宿主“设置 → 导入与备份”导入页面，信任并校验清单后启用，
刷新浏览器进入“行业强度与MA55”。不需要重启宿主或 MA55。
回退只需停用此页面；不删除或改动其他已安装扩展及行情数据。

## 官方口径缺口

宿主 `ext_presets.py` 明示扁平来源，但 `ext_fanout.py` 的 `-` 拼接丢失原始目录身份；
`rps_rotation.py(level=2)` 又按该字符投影层级，官方行业对话框默认选2级。
本插件不传层级、不修核心文件、不改变官方页面；原官方入口的口径缺口仍然存在。

扩大到其余歧义记录需要源提供保留目录 ID 的股票—行业关系，或经核实的原始目录映射，
并带源版本/观察时间；不能从拼接字符串反推。层级展示还需要独立可信父子关系。
历史行业成分版本、权威行业指数、真实资金流、自动AI和动态重点池均未接入。

本轮实际样本和验证见 [ACCEPTANCE_20261114.md](ACCEPTANCE_20261114.md)。
