## 实际实现

- `indicator_cache.py`：同一SQLite新增`chart_cache`，每证券15/30/60m三个有界快照，保存OHLCV、六SMA、来源/基准/因子/日历修订、元数据及最多233个滚动收盘。raw15继续是行情事实。
- `market_store.py`：连续新K在原事务内追加指标；历史补缺、修订、因子或来源变化使相关缓存失效。首次与修订重建由空闲writer执行，最新K与冻结计算优先。每233步用`math.fsum`重定滚动和；重启从保存状态恢复。
- `market_grid.py`、策略适配读取：策略只投影必要价格/因子，不重复计算图表六MA；冻结pipeline继续独立计算自己的因果特征。缓存不参与BUY判定。
- `extension.py/runtime.py`：当前窗口命中时只读缓存；历史窗口/未建缓存从至多1280根保存raw有界重建并返回`cache.hit=false`。GET只登记缓存重建需求，不发商业行情请求或重算BUY。原商业冷历史队列保持独立。
- `collector.py/native15_shadow.py`及tools：原生仅供受控对照，真实HTTP hook把所有分钟period计入原分钟池，保留失败计数、零自动重试及原429冷却语义。未新增在线SDK owner。
- `src/status-view.mjs/styles.mjs/results.mjs`：五张核心卡、卡内小进度、简短运行带、默认折叠诊断、260px搜索及原三列表。正文继承TSP的Inter字体栈，数字使用其JetBrains Mono / IBM Plex Mono字体栈；颜色来自宿主主题令牌。
